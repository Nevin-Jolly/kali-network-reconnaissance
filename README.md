# Kali Linux – Network Reconnaissance and Scanning

## Overview

This repository contains my Week 2 cybersecurity practical work covering website footprinting and network scanning using Kali Linux.

The project demonstrates the use of various reconnaissance tools to gather publicly observable information about a website and discover active devices within a local network.

## Modules Completed

### W2-PM1 – Footprinting with Six Kali Tools (Elective)

Tools used:

1. **WHOIS** – Domain registration information.
2. **WhatWeb** – Website technology fingerprinting.
3. **nslookup** – Domain-to-IP address resolution.
4. **curl -I** – HTTP response header analysis.
5. **WAFW00F** – Web Application Firewall detection.
6. **DNSRecon** – DNS record enumeration.

### W2-PM5 – Zenmap-Based Network Scanning (Essential)

- Tool: Zenmap / Nmap
- Scan type: Ping Scan
- Target: `192.168.1.0/24`
- Result: 6 active hosts discovered out of 256 IP addresses.
